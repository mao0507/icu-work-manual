# 肋膜積液

當出現肋膜積水時，臨床上會進行**胸腔穿刺**抽取胸水，並進行常規分析、結核相關檢查、胸水培養，以及同時抽血檢測**總蛋白（TP）與乳酸脫氫酶（LDH）**，以進一步區分漏出性與滲出性胸水並釐清病因，再針對分析給予治療。

## 漏出性（Transudate）

主要由**全身性或器官性疾病**引起，包括三個方面：

1. 靜脈阻塞或回流受阻，使毛細血管內壓力升高，導致血管內液體滲出；或因淋巴管與胸導管阻塞，使淋巴回流受阻而在組織間隙累積。
2. 血漿白蛋白濃度明顯下降，使血管內膠體滲透壓降低，進而促使液體自血管內濾出增加。
3. 腎臟排鈉排水功能下降，造成鈉與水滯留，使組織間液增加，最終形成漿膜腔內的漏出液。

## 滲出性（Exudate）

主要由**局部發炎或腫瘤**所造成。發炎性原因可分為感染性與非感染性：

- 感染性：細菌、病毒或真菌感染
- 非感染性：胰臟炎、肺栓塞及結締組織疾病等

此外，腫瘤性原因亦相當常見。

## 計算方式（Light's Criteria）

- 肋膜積水／血清**蛋白質**比值
- 肋膜積水／血清 **LDH** 比值
- 計算完畢再用判別圖區分漏出／滲出性

::: details 牛刀小試
根據下列數值判斷漏出／滲出性：

- 胸水蛋白值：5.6 g/dl
- 胸水 LDH 值：292 IU/L
- 血中全蛋白值：7.0 g/dl
- 血中 LDH 值：172 IU/L

**計算：**
- 蛋白比值 = 5.6 / 7.0 = **0.80**（> 0.5）
- LDH 比值 = 292 / 172 = **1.70**（> 0.6）

兩項皆超過閾值 → **滲出性（Exudate）**
:::

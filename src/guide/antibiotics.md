# 常用抗生素

下圖為 **Antibiotic Sensitivity Overview**（抗生素敏感性總覽），依菌種分類：

- **Gram Positive Cocci**：MRSA、MSSA、Streptococci
- **Gram Negative Bacilli**：E.coli／Klebsiella、Proteus、Pseudomonas、ESCAPPM
- **Anaerobes**（厭氧菌）

常見對應藥物舉例：

| 菌種 | 可考慮藥物 |
| --- | --- |
| MRSA | Vancomycin／Teicoplanin、Linezolid、Daptomycin、Rifampicin/Fusidic Acid |
| MSSA | Flucloxacillin、Cephazolin、Clindamycin |
| Streptococci | Penicillin、Amoxycillin |
| Gram (−) | Amoxycillin-clavulanate、Piperacillin-tazobactam、Cephalosporins（Cefuroxime/Ceftriaxone/Ceftazidime/Cefepime）、Quinolones（Ciprofloxacin/Moxifloxacin）、Aminoglycosides（Gentamicin/Tobramycin）、Carbapenems（Meropenem/Imipenem/Ertapenem） |
| Anaerobes | Metronidazole、Clindamycin、Amoxycillin-clavulanate、Piperacillin-tazobactam |

::: warning
使用抗生素時也要考慮**肝腎功能**。ESBL-producing organisms 對多數含 beta-lactam ring 抗生素**無效**，通常選用 carbapenems。
:::

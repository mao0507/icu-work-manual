# 拔管指標（WEANS NOW）

**WEANS NOW** 為影響脫離呼吸器是否成功的因素。

## Weaning parameter（重要指標）

- 在 **FiO2 < 50%** 的條件下，PaO2 能夠超過 **60 mmHg**
- **PaO2/FiO2 > 200**
- **PEEP < 5 cmH2O**
- CO2（< 50 mmHg）和 pH（> 7.35）在可接受範圍
- 請 RT 測 RSBI、Tidal volume、RR、Minute ventilation（暫時脫離呼吸器 1 分鐘測出）：

| 指標 | 標準 |
| --- | --- |
| **RSBI**（rapid shallow breathing index） | < 105 breaths/min/L（算法：每分鐘呼吸次數 / tidal volume；RSBI 越高，呼吸越淺快） |
| **Tidal volume** | > 5 cc/kg（身體重量 × 7 mL/kg） |
| **Respiratory rate** | < 30 |
| **Minute Ventilation** | < 10–15 L/min（潮氣容積 × 呼吸次數） |

## WEANS NOW 各因素

| 字母 | 因素 | 重點 |
| --- | --- | --- |
| **E**ndotracheal tube | 氣管內管 | 盡可能使用較大號的氣管內管，呼吸阻力較小；考慮使用 PS mode 戒除呼吸器；抽吸分泌物 |
| **A**rterial blood gas | 動脈血液氣體 | PaCO2 < 50、pH > 7.35；避免或矯正代謝性鹼中毒；維持氧分壓 60–65 mmHg；CO2 滯留病人應將 PaCO2 維持在基準濃度以上 |
| **N**utrition | 營養 | 避免營養不良、電解質不平衡 |
| **S**ecretion | 分泌物 | 拔管前要把分泌物都抽掉 |
| **N**euromuscular factor | 神經肌肉 | 避免使用神經肌肉鬆弛劑（盡早戒除鎮靜及肌肉鬆弛劑）；避免不必要使用皮質類固醇（易造成肌無力） |
| **O**bstruction of airway | 氣道阻塞 | 適當使用氣管擴張劑並排除呼吸道中的異物 |
| **W**akefulness | 清醒度 | 避免在 sedation（鎮靜）下進行拔管 |

# 常用評估量表（GCS）

## GCS 評分（昏迷指數）

| 反應 | 滿分 |
| --- | --- |
| 睜眼反應（E, Eye opening） | 4 分 |
| 說話反應（V, Verbal response） | 5 分 |
| 運動反應（M, Motor response） | 6 分 |

滿分 **15 分**，昏迷程度越重者的昏迷指數越低分，**最低為 3 分**。

::: tip
評分要以**最佳分數**記載。
:::

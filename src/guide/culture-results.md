# 辨識培養結果

每個抗生素後面會有 **S、I、R** 三個符號，代表的是：

| 符號 | 意義 |
| --- | --- |
| **S**（Sensitive） | 對藥物敏感的／**有效** |
| **I**（Intermediate） | 介於有效和無效之間 |
| **R**（Resistant） | 有抗藥性的／**無效** |

所有標示 **S（Sensitive）** 的藥物，都是可以考慮的。

當有新的培養結果出來，可查看現正使用的抗生素是否有效，可告知當科提出是否更換抗生素。

::: tip 最簡單的記法
**S** → Sensitive 敏感的 → **Super 有效**
:::

::: warning
使用抗生素時也要考慮**肝腎功能**。
:::

# 接下刀（術後病人）

## 前置作業

當確定知道會接術後病人時，先了解來源，分為**急診**及**病房**：

- **急診**：不用跟急診交班，下刀時會由手術室護理人員交班
- **病房**：要跟病房電話交班，可以先看系統，有疑慮的要向對方確認醫囑、藥物、備註等

拿好單張（入住加護病房說明書、TPR 單、購物清單）、手圈、床頭、醫師牌。

OR 會打來問要給哪床，告知備物（通常是全套），備好用物後才 CALL 傳送推床到 OR。

::: danger 床要記得歸零！
床要**歸零、歸零、歸零**才可以推床。如果有上氣墊床，要**含主機一起**歸零。
:::

## 病人從手術室回來

- → 固定床輪，避免病安事件
- → Call RT、Call NP（白班找當科或 ICU 專師；小夜／大夜班找值班專師）
- → 接上氧療、BP Cuff、EKG、換衣服
- → 檢查全身**管路**：確認管路公分數、位置，管路引流是否通暢，引流液顏色、性質
- → 檢查全身**皮膚**：釐清大小、位置、是否因手術擺位有壓傷，術後傷口有無滲血情形。主護要記得自己確認過皮膚情形，**尤其是背部、薦骨、骨凸處**
- → 家屬在外面：整好病人後請他進入，說明 ICU 規定、給購物單、問轉出床位／誰顧
- → 主護交班（與麻醉科、手術室）。注意重點：**手術診斷、術式、麻醉方式、切除部位、引流管置放位置、術中有無特殊事件、術中輸液量、失血量、植入物、術後敷料、傷口如何覆蓋**

## 整理思緒

- → 請病人家屬進入看病人，講解生理監測器數值代表意義，**不解釋病況！！**
- → 簽署 Ambu 同意書、約束同意書、寶馬生同意書（帶 ENDO 回來的才有同意書）
- → 若手術室有耗材要補自費同意書的，請務必問**計價碼**
- → 確認病人現況，檢視有無立即要處理的醫囑
- → 依醫囑留檢體、驗血糖
- → 打轉入加護病房原因、紀錄、備註特殊交班
- → 下跌倒、壓瘡評估，傷口系統要上傳，心理自殺因子評估
- → 手術全期輸入**接班時間點**
- → 計價

# ABG 判讀

動脈血液分析中 **pH、PaCO2、PaO2、HCO3、O2sat、BEefc** 這些數值可用來幫助我們：

- 評估肺部氧氣交換的功能，作為診斷依據
- 評估氧氣治療的效果
- 評估病患的呼吸機制是否正常
- 評估血中的酸鹼平衡

## 判讀步驟

主要判讀 **pH、PaCO2、HCO3、BEefc** 數值。

1. 判讀酸鹼值
2. 判讀呼吸性／代謝性
3. 判讀有無代償
4. 判讀 BEefc

## 判讀原則

| | 酸 | | 鹼 |
| --- | --- | --- | --- |
| **pH** | < 7.35 | pH | > 7.45 |
| **PCO2** | > 45 | PCO2 | < 35 |
| **HCO3⁻** | < 22 | HCO3⁻ | > 26 |

1. **pH**：酸性 < 7.35–7.45 > 鹼性
2. pH 及 CO2 改變**方向相同** → 代謝性；pH 及 CO2 改變**方向相反** → 呼吸性
3. pH、HCO3⁻ 與 CO2：
   - 前者異常，後者一酸一鹼 → **部分代償**
   - 前者正常，後者一酸一鹼 → **完全代償**
4. 假如 BEefc = −8 mmol/L，代表每公升的血液缺乏 8 mmol 的 HCO3，有時會因此而補 **Sodium Bicarbonate** 用來矯正酸。

::: details 牛刀小試
動脈血液氣體分析結果為 pH 7.25、PaCO2 48 mmHg、PaO2 65 mmHg、HCO3⁻ 22 mEq/L、BE −1.5、SaO2 80%，下列臨床判斷何者正確？

(A) 代謝性酸中毒　(B) 呼吸性酸中毒　(C) 呼吸性鹼中毒　(D) 代謝性鹼中毒

**解答：(B) 呼吸性酸中毒**
（pH 低為酸；PaCO2 升高，pH 與 CO2 方向相反 → 呼吸性）
:::

# 鎮靜評估量表（RASS）

**RASS** 為針對加護病房使用呼吸器個案具信、效度的鎮靜狀態評估工具，臨床表現狀況評分由 **+4 到 −5**。

::: tip
當 RASS 評分介於 **−3 到 +4**，才使用 **CAM-ICU** 做譫妄評估。
:::

## RASS 鎮靜程度評估表

| 分數 | 狀態 | 臨床表現 | 處置 |
| --- | --- | --- | --- |
| **+4** | 有攻擊性 | 有暴力行為 | 調整劑量 |
| **+3** | 非常躁動 | 試著拔除呼吸管、鼻胃管或靜脈點滴 | 調整劑量 |
| **+2** | 躁動焦慮 | 身體激烈移動，無法配合呼吸器 | 調整劑量 |
| **+1** | 不安焦慮 | 焦慮緊張、但身體只有輕微移動 | 理想狀況 |
| **0** | 清醒平靜 | 清醒，自然狀態 | 理想狀況 |
| **−1** | 昏昏欲睡 | 沒有完全清醒，但可維持清醒超過十秒 | 理想狀況 |
| **−2** | 輕度鎮靜 | 無法維持清醒超過十秒 | 理想狀況 |
| **−3** | 中度鎮靜 | 對聲音有反應（but no eye contact） | 調整劑量 |
| **−4** | 重度鎮靜 | 對身體刺激有反應 | 調整劑量 |
| **−5** | 昏迷 | 對聲音及身體刺激都沒有反應 | 調整劑量 |

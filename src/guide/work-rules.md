# 工作守則

| 守則 | 內容 |
| --- | --- |
| 守則一 | 勤洗手、多喝水、定時上廁所。照顧好自己，才能照顧好病人 |
| 守則二 | 眼觀四面、耳聽八方。聽見警報請前去查看，不要漠視 |
| 守則三 | 顧好所有管路，勿滑脫、防自拔 |
| 守則四 | 離開病室請告知左右旁護 |
| 守則五 | 互相尊重、理性溝通、互相幫忙、共同成長 |
| 守則六 | 不清楚、不明白、不知道、沒把握的事，請務必問清楚、想明白 |

::: tip 給你的話
對自己負責，對別人負責。下班回家，好好吃飯，好好休息，每天都會比昨天更好。

遇到不會的記下來，回家查書、查網路、問學姊、問前輩。

**你超棒的，你是最棒的！**
:::

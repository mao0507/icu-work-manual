# 壓力性損傷

## 分級

| 分級 | 名稱 | 特徵 |
| --- | --- | --- |
| Stage 1 | 發紅但皮膚完整 | 局部皮膚出現**按壓不反白**的紅斑，通常位於骨突出處 |
| Stage 2 | 部分皮層缺損 | 真皮層的一部分皮層損傷，表現為淺表的開放性潰瘍，呈紅粉色，無腐肉 |
| Stage 3 | 全層皮層缺損 | 皮層損傷，可見皮下脂肪，但骨骼、肌腱、肌肉並未暴露，可能存在腐肉 |
| Stage 4 | 全層皮層及組織缺損 | 全皮層組織損傷，導致骨骼、肌腱或肌肉暴露在外；可能呈現腐肉或結痂，通常包含潛行和隧道型傷口 |
| Unstageable | 無法分級 | 全層皮層缺損，深度未知；傷口床基底部覆蓋腐肉（黃、黃褐、灰、綠或棕色）和／或痂皮（黃褐、棕或黑色） |
| DTI | 深部組織壓力性損傷 | 皮膚持續性呈現無法反白的深紅色、褐色或紫色病灶；可能皮膚完整或不完整，或表皮分離，顯示出暗黑色的傷口床或充血的水泡 |

![壓力性損傷各期外觀對照](/image/img-022-019.png)

::: tip 小提醒
皮膚是重要的器官，照護病人時需要非常注意呵護，尤其是**管路置放部位**（鼻胃管、氣管內管、引流管等），不僅要注意管路位置也需注意管路周圍皮膚，及**骨突處、易受壓部位**。

若有皮膚上疑問可尋求**傷口照護師**協助，照會時需告知傷口現狀、傷口大小、照護方式、如何形成的傷口等資訊。
:::

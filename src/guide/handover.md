# 交接班注意事項

## 系統與紙本檢核

1. 了解**診斷、病史、入院經過、檢查報告、抽血報告、近日病程變化**。
2. Check 是否有**待抽血、痰液、糞便化驗**檢驗項目（日期與時間）。
3. Check 是否有**待檢查項目**（檢查單、檢查日期與時間、所有同意書完整性：診斷、檢查名稱、醫師部分、家屬病患部分、Sign in 日期與時間）。
4. 有簽立 **DNR**：
   - 確認紙本內容、確認醫囑開立、確認同意書完整性
   - 意識清醒 → 簽立 **DNR 意願書**；意識不清醒 → 簽立 **DNR 同意書**
   - 確認院宣？DDT？路程時間？

## 到病室與上一班護理人員共同檢視病人

5. Check **管路**固定公分數、管路到期日、管路是否通暢／紅腫／滲液、GCS／V/S baseline、肌力、pupil size、light reflex（神內神外病人）、皮膚完整性、壓傷（評估各種管路、氧療面罩等放置處是否壓瘡）、傷口情形、引流管位置。
6. Check 交接的**點滴**品項？剩餘哪些靜脈輸液容液量與品項？
7. Check **IV pump** 的輸液品項、效期與滴數，並將總量幫浦歸零，檢視剩餘總量。
8. Check **藥物數量**。週五 UD 藥車有 3 天份（週五 16:00 至週一 15:00），遇上國定假日時 UD 藥車會多發國定假日的量。

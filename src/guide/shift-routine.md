# ICU 三班常規

三班（白班、小夜、大夜）工作時序如下表。共同原則：**簽到、點班、核對醫囑、核對藥物數量**開始；**檢視有無遺漏事項、約束檢核、管路評核、檢視紀錄、上傳紀錄、簽退**結束。

## 白班（08:00–16:30）

| 時間 | 工作內容 |
| --- | --- |
| 08:00 前 | 簽到、點班、核對醫囑、核對藥物數量 |
| 08:00–08:30 | 交班、翻身、發洗澡用布、床上擦澡、量體溫 |
| 08:30–10:00 | 給藥、治療、檢查、醫師查房、床上擦澡、feeding |
| 10:00–10:30 | 書寫護理紀錄、管路照護評核、每日身體評估、翻身 |
| 10:30–11:00 | 會客 |
| 11:00–11:30 | 翻身、給藥、測血糖 |
| 12:30–13:30 | 灌食、給藥、書寫護理紀錄、主護用餐 |
| 13:30–14:00 | 翻身、量體溫、做治療 |
| 14:00–14:30 | 會客 |
| 14:30–15:00 | 翻身、統計 I&O、key in 系統 I&O |
| 15:00–15:30 | 做治療、書寫護理紀錄 |
| 15:30–16:00 | 整理病室、準備交班 |
| 16:00–16:30 | 交班、翻身 |

## 小夜班（16:00–00:30）

| 時間 | 工作內容 |
| --- | --- |
| 16:00 前 | 簽到、點班、核對醫囑、核對藥物數量 |
| 16:00–16:30 | 交班、翻身、量體溫 |
| 16:30–17:30 | 給藥、治療、量血糖 |
| 17:30–18:30 | 書寫護理紀錄、管路照護評核、每日身體評估、翻身 |
| 18:30–19:00 | 翻身 |
| 19:00–19:30 | 給藥、書寫護理紀錄 |
| 20:00–20:30 | 給藥、量體溫、量血糖 |
| 20:30–21:00 | 翻身 |
| 21:00–21:30 | 灌食、做治療 |
| 21:30–22:30 | 給藥、書寫護理紀錄 |
| 22:30–23:00 | 翻身 |
| 23:00–00:00 | 統計 I&O、key in 系統 I&O、整理病室、準備交班 |
| 00:00–00:30 | 交班、翻身 |

## 大夜班（00:00–08:30）

| 時間 | 工作內容 |
| --- | --- |
| 00:00 前 | 簽到、點班、核對醫囑、核對藥物數量 |
| 00:00–00:30 | 交班、翻身、量體溫、發晨間盥洗布單（枕頭套×1＋小毛巾×2） |
| 01:00–01:30 | 給藥、灌奶、整理病歷 |
| 01:30–02:00 | 書寫護理紀錄、管路照護評核、每日身體評估 |
| 02:00–02:30 | 翻身 |
| 03:30–04:00 | 補各式各樣耗材、補點滴、換到期耗材（含留置針）<br>Morning care（頭以上 line care、CVP care、wd care）、皮膚系統更新 |
| 04:00–05:30 | 抽血、量血糖、給藥、灌奶、量體溫 |
| 05:30–06:00 | 翻身（當日沒有要照 CXR 的病人） |
| 06:00–06:30 | 照 CXR、秤體重（當日需行血液透析病人） |
| 07:00–07:30 | 做治療、統計 I&O、key in 系統 I&O、查看抽血結果 |
| 07:30–08:00 | 書寫護理紀錄、整理病室、準備交班 |
| 08:00–08:30 | 交班、翻身 |

::: warning 血糖機校正
血糖機校正由**大夜班**負責，**凌晨三點前完成**。
:::

# 常見呼吸器模式

常見模式：

- PCMV
- PCV/AC
- PSIMV (VC/PC)
- SIMV+PS
- PSV
- CPAP

## 常用參數

| 參數 | 全名 | 說明 |
| --- | --- | --- |
| **TV** | Tidal volume | 潮氣容積 |
| **IP** | Inspiration pressure | 吸氣壓力 |
| **RR** | Respiratory rate | 呼吸次數 |
| **FLOW RATE** | — | 氣流量 |
| **Ti** | Inspiration time | 吸氣時間：0.9–1.5″ |
| **FiO2** | Fraction of inspiration O2 | 吸入氧氣濃度：通常 40–60%（依需求調整） |
| **PEEP** | Positive End Expiratory Pressure | 吐氣末端陽壓：通常 5–20 cmH2O 或依需求 |
| **MV** | Minute ventilation volume | 每分鐘進出肺的氣體總量 = 呼吸頻率 × 潮氣量 |

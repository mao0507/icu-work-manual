# 隔離種類與 ANC 計算

## 隔離時機

| 隔離種類 | 時機 |
| --- | --- |
| 接觸性隔離 | Culture 為 **CR、VRE** |
| 預防性隔離 | 從**外院、護理之家、機構**入本院 |
| 保護性隔離 | **ANC < 500** |
| 空氣隔離 | 確診 TB、PCR positive、sputum AFS: was found、sputum TB/C: 結核分枝桿菌、水痘、麻疹、瀰漫性帶狀皰疹 |
| 疥瘡隔離 | 疑似或確診疥瘡 |
| 飛沫隔離 | SARS |
| 腸道隔離 | Salmonella species 沙門氏桿菌 |

## 隔離措施配備

| 隔離種類 | 配備 |
| --- | --- |

| 預防性隔離 | **黃色膠帶**、隔離桶、隔離牌、隔離衣、乳膠手套、口罩 |

| 空氣隔離 | **負壓隔離病房**、啟動負壓（call 工務）、**N95 口罩** |

## 轉出隔離病患環境處理方式

1. 導線儀器以 **75% 酒精**洗手液擦拭。
2. 聯絡清潔清床及更換圍簾窗簾。

### 疥瘡病患床墊處理方式

1. 著裝隔離衣、乳膠手套完整，搬動床墊至尚未啟用的病室空間**曬太陽**。
2. 搬回一張床墊使用。

## ANC 計算

**絕對嗜中性白血球數（ANC）**：指白血球中的嗜中性白血球（neutrophil）之多形核白血球（segment）及帶狀白血球（band）的數量。

計算公式：

$$ANC = (Seg\% + Band\%) \times WBC$$

::: details 牛刀小試
病人接受化學治療前 WBC 2,000/mm³、seg 30%、band 5%、monocyte 15%、Hb 9.5 g/dL、platelet 200,000/mm³，請問絕對嗜中性白血球（ANC）為多少？

(A) 400/mm³　(B) 600/mm³　(C) 700/mm³　(D) 1,000/mm³

**解答：(C)**　(30% + 5%) × 2000 = **700/mm³**
:::

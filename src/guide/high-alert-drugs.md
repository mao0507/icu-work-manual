# 高警訊藥物泡製

## 泡製濃度

| 藥物 | 泡製 |
| --- | --- |
| Norepinephrine (Levophed) | 8mg in D5W 250ml；16mg in D5W 250ml |
| Dopamine | 400mg in N/S 250ml；400mg in N/S 240ml |
| Vasopressin | 40U in D5W 98ml |
| Epinephrine | 10mg in N/S 250ml |
| Midazolam (Dormicum) | 50mg in N/S 90ml；100mg in N/S 80ml |
| Fentanyl | 0.5mg in N/S 90ml；1mg in N/S 80ml |
| Nimbex (cisatracurium) | 50mg in N/S 50ml 或純液不稀釋 |
| Aminophylline | 500mg in N/S 500ml |
| Amiodarone | 900mg in D5W 500ml；900mg in D5W 82ml |
| Isosorbide dinitrate (Angidil) | 20mg in N/S 80ml |
| Heparin | 10KU in N/S 90ml |
| Dobutamine | 500mg in N/S 250ml；500mg in N/S 210ml |
| Actrapid HM | 50IU in N/S 500ml；100IU in N/S 100ml（1:1） |

## 藥物濃度計算

**Levophed（Norepinephrine）：**

$$\frac{劑量(mg) \times 1000}{溶液量 \times 60}$$

**Dopamine／Dobutamine／Midazolam（與體重相關）：**

$$\frac{劑量(mg) \times 1000}{體重 \times 溶液量 \times 60}$$

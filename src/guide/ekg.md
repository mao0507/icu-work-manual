# 12 Lead EKG

12 leads ECG 利用十二個位於正面與水平面上的導程，記錄心臟十二個不同方向的電氣生理活動，能從十二種不同的角度觀察去極化波，再依心電圖變化判斷心肌受損的位置。如果懷疑是**後壁梗塞**會額外用 **V7–9** 或是 **Right side ECG** 做判讀。

## 貼片位置

### 胸前導極

| 導極 | 位置 |
| --- | --- |
| V1 | 第四肋間胸骨**右**緣 |
| V2 | 第四肋間胸骨**左**緣 |
| V3 | V2 及 V4 間的中點 |
| V4 | 左胸第五肋間的鎖骨中線處 |
| V5 | 左胸第五肋間的腋前線 |
| V6 | 左胸第五肋間的腋中線 |

### 肢體導極

肢體導極應**對稱置於四肢**：LA 置於左手、RA 置於右手、LL 置於左腳、RL 置於右腳。

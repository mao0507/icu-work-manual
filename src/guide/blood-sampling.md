# 採血正確順序與血液培養

## 血液培養

抗生素血液培養瓶分為：

1. **需氧瓶（Aerobic）**：灰蓋藍頭、塑膠瓶
2. **厭氧瓶（Anaerobic）**：橘蓋金頭、塑膠瓶

建議樣品採量至少 **5–10ml** 的血液。

### 以「安全採血針具」採集血液培養流程

1. 使用 Barcode 抽血系統 → 列印檢驗標籤 → 識別護理人員 ID → 完成採血 → 刷病人手圈條碼
2. 正確執行皮膚清潔 → 採血者手部洗手 → 採血部位以 **2% CHG 環形消毒二次，直徑 3 吋**；第一次環形消毒等待 30 秒或乾燥後，第二次再環形消毒等待 30 秒
3. **酒精棉片**擦拭血瓶塑膠瓶口：第一次環形消毒等待 30 秒或乾燥後，第二次再環形消毒等待 30 秒
4. 採血：需氧瓶（Aerobic）→ 厭氧瓶（Anaerobic）
5. 再次黏貼病人試管條碼標籤
6. 送檢前再次確認已完成 Barcode 抽血系統、床號、病人姓名、試管等無誤，送出檢體至檢驗科

::: warning 打血順序
- **空針**採血之打血順序：厭氧瓶（Anaerobic）→ 需氧瓶（Aerobic）
- **安全針具**採血之打血順序：需氧瓶（Aerobic）→ 厭氧瓶（Anaerobic）
:::
